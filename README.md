# Bioberries Logger

This repository contains the Bioberries Sales WordPress plugin for the
Bioberries Logger project.

## Installation

Requirements:

- WordPress 6.9 or later
- PHP 7.4 or later
- The [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter) to
  expose the project's ability over MCP

Install and activate the WordPress MCP Adapter separately. Then copy
`wp-content/plugins/bioberries-sales` into the `wp-content/plugins/` directory
of your WordPress installation and activate **Bioberries Sales** from the
WordPress admin.

The local WordPress core, configuration, database, and uploads are not
included in this repository. The third-party MCP Adapter is also not bundled.
