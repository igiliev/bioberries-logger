# Bioberries Logger

This repository contains the Bioberries Sales WordPress plugin for the
Bioberries Logger project.

## Installation

Copy `wp-content/plugins/bioberries-sales` into the `wp-content/plugins/`
directory of a WordPress installation, then activate **Bioberries Sales**
from the WordPress admin.

The local WordPress core, configuration, database, and uploads are not
included in this repository.
